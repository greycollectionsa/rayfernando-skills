# Source policy

SEO and agent installation guidance changes. When a claim is platform-specific or current-state dependent, prefer primary sources and verify the current version.

## Rules
1. Use current official/primary documentation for crawler names, install paths, commands, supported schema, limits and platform requirements.
2. Do not turn experimental community practices into platform requirements.
3. If official sources disagree with a secondary blog, prefer the official source.
4. Separate fact from inference.
5. Include the date/version when a recommendation is likely to change.
